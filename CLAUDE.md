# nce-talk

pnpm monorepo: `apps/api` (Express), `apps/web` (Next.js), `packages/*`.

## Starting the dev environment

Run each app in its own tab of the Claude app's terminal panel, so both the developer and Claude can see the console output.

- Tab `api`: `pnpm dev:api`
- Tab `web`: `pnpm dev:web`

Run both from the repo root.
