- CLAUDE.md

  If you find Claude keeps running into the same issues, ask it to save the solution to its CLAUDE.md file.

  For things you want Claude to remember across sessions, put them in your CLAUDE.md file so it doesn't have to rediscover things from scratch.

  When the reviewer flags the same issue a few times, it might be a good idea to write a rule for Claude to read at the start of every session.

  If you find yourself correcting Claude repeatedly — like telling it to always use server actions instead of API routes — explicitly ask Claude to save that rule to memory.

  Reference project docs. If you have documentation in your project that you want Claude to reference, use the @ symbol with the file path
